# Сверка партий Сакаева с PDF (для помощника)

Рабочая папка: `tools/sak`. Текст партий (.md) распознан с ошибками: перепутаны фигуры
(Bxc4 вместо Nxc4), поля, иногда целые куски ходов выдуманы. Правильно — только в скане книги.
Твоя задача: для каждой своей партии добиться «чисто» в `status.py`, исправляя ходы ТОЛЬКО по скану.

Свои переменные (подставь свой номер K):
    export FIX_EXTRA=fix_aK.json ALIGN_OUT=work/align_aK.json
    D=/private/tmp/claude-501/-Users-vadimsamalo-Documents-kombinatorika/ed89575c-4a19-43f3-808a-41e8e7f84cfb/scratchpad/pdf/aK; mkdir -p $D

Цикл по партии N:
1. `python3 align.py > /dev/null && python3 status.py N` — где рвётся главная линия: ход, позиция (FEN),
   строка .md и строки распознанного PDF с этим номером хода (распознанный PDF неточен: значки фигур
   могут быть мусором, но поля обычно верные).
2. Посмотреть книгу — только вырезки, не страницы:
   - `OUT=$D python3 look.py N 17... 19.` — строки с этими ходами (выбирается жирная строка главной линии),
   - `python3 tail.py N 23... $D/tN.png` — от хода до конца партии (если картинка выше ~1300 px — не открывай, режь look.py),
   - `python3 sheet.py $D/s.png a.png:подпись b.png:подпись` — склеить несколько вырезок в одну картинку.
   Открывай картинку Read. Главная линия в книге — ЖИРНЫМ; комментарии и варианты — обычным шрифтом.
3. Если позиция обрыва противоречит книге раньше (не хватает фигуры и т.п.) — расхождение выше по партии:
   `python3 -c "import json,os;A=json.load(open(os.environ['ALIGN_OUT']));g=next(x for x in A['games'] if x['title'].startswith('N.'));print(' '.join(x[1] for x in g['line'] if x[0]=='mv'))"`
   — сыгранная линия; сравни с книгой и найди первое расхождение.
4. Правка — в СВОЙ файл fix_aK.json (создай: {"patches": [], "fens": {}}):
   {"game": "N", "from": "точная подстрока из .md в разделе партии", "to": "как в книге", "pdf": "стр. 61"}
   «from» бери как есть из строки md, выведенной status.py (с ** если они там), достаточно длинной, чтобы быть уникальной.
   Ходы пиши латиницей: K Q R B N, рокировка 0-0. Знаки !? и + сохраняй как в книге.
   Если неверна сама стартовая доска партии (из файла досок) — "fens": {"номер доски файла": "расстановка FEN (только первое поле)"}.
   Номер доски файла — поле start в align (см. п.3: g['start']).
5. Повтор с п.1, пока не «чисто». Если «правка не найдена» — from не совпал с текстом.

Правила:
- Только то, что видно в скане. Не угадывай ход по легальности, не правь комментарии и варианты.
- Не трогай чужие партии, общие файлы (fix.json, lib.py, align.py, *.md) и work/align.json.
- Партия, которую не удаётся довести за ~6 вырезок, — пропусти и опиши почему.
- В конце: список партий «чисто / не удалось (почему)» и число правок.
